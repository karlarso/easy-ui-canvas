# 简体中文

## Easy UI Canvas v0.1.0 —— 首个公开版本

一个本地运行的多画板（多帧）UI 探索画布：让 AI 编程 agent 把多个 HTML 界面并排画在可缩放、可平移的画板上，你直接**点元素写评论**，agent 在下一轮会话里读取评论、修改并回复。只依赖 Python 3 标准库，无需账号、无需 token、数据都在本机。

### ✨ 亮点
- 🗂️ **多帧画板（Tile 视图）**：缩放、平移、小地图、适应窗口；帧就是 agent 写的 HTML/CSS 片段，是真代码而不是图片。可用 `group` 把帧分成带标题栏的分区，每个分区可单独设置列数。
- 💬 **元素级评论**：点击任意元素（也可以是整个帧、帧标题、分组标题栏，或画板上的独立备注）即可评论；状态分为「待处理 / 已修改 / 需讨论」；一键「复制给 AI」；agent 可用命令行读取并回复。
- 📱 **Flow 视图与手机预览**：给按钮加 `data-goto` 即可把原型变成可点击流程；Flow 视图里也能开评论模式对当前页面评论（点击只选中不跳转）；`/m/` 是只读手机页（带二维码，需要手机能访问的非本机绑定地址）。`data-keep-scroll` 可在状态间保持滚动位置。
- 🕘 **快照**：保留历史版本及其评论，只读回看。
- 📋 **多画板 + 列表页**：每个画板是一个小服务，列表页可启动 / 停止 / 删除（删除进入 trash，可恢复）。
- 📤 **UI hand-off 导出**：一个 ZIP，含离线页面、截图、资源和 `HANDOFF.md`（需自行安装可选工具 Node.js + Playwright + Chromium/Chrome）。
- 🌐 **中英文界面**（列表页切换，含服务端报错和 CLI 输出）。
- 🪶 **无构建、无 CDN、无第三方 Python 包**；画板就是目录里的普通文件（HTML、JSON、素材），可以放进 git。
- 🤖 **作为 agent skill 使用**（Claude Code / Cursor / Codex）：`SKILL.md` + `DEPLOY.md`，一句话让你的 AI 助手自己部署；也提供「已在运行，仅安装 skill」的一句话。

### 本版本相对早期提交的主要变化
- Flow 视图支持评论（#11）
- 可评论整个画板范围：画板备注、分组标题栏（#10）
- Tile 视图按分组分区、每区独立列数（#8）
- 修复：评论输入框内空格始终可输入（#9）
- Flow 视图在状态间保持内部滚动位置 `data-keep-scroll`（#6）
- 文档：一句话部署 / 仅装 skill、使用示例、中文润色、CONTRIBUTING、SECURITY（#1–#7 等）

### ⚠️ 已知限制 / 注意事项
- **没有任何认证**：默认只监听 `127.0.0.1`，且拒绝非回环 `Host`；若用 `--host 0.0.0.0` / LAN 地址对外开放，任何能访问的人都能读写评论、删除画板，只在可信网络使用。
- 仅支持 macOS / Linux（Windows 通过 WSL）；需要 Python 3.9+。
- 页面不会自动刷新：agent 改完帧或回复评论后，需要手动刷新浏览器页面才能看到。
- 帧 HTML 里的脚本不会执行；不要导入不可信的第三方页面作为帧。
- 手机预览 `/m/` 只读，且手机必须能访问画板地址（需非本机绑定）。
- UI hand-off 导出依赖可选外部工具（不随仓库分发、不会自动安装）；导出 ZIP 不含评论，也没有「一键导入 ZIP」命令（由 agent 解压后按 `HANDOFF.md` 新建画板）。
- 它用于对比 UI 方向与状态，**不是**用来交付生产应用的工具。
- 外部 Pull Request 暂不接受（见 CONTRIBUTING.md）；欢迎提 Issue。

### 🚀 快速开始
**方式一：让 AI 助手部署（推荐）** —— 把下面这句话发给你的 AI 助手（Claude Code / Cursor / Codex …）：
```text
Read https://raw.githubusercontent.com/karlarso/easy-ui-canvas/main/DEPLOY.md and deploy Easy UI Canvas by following it. Ask me about the bind address and autostart before you change anything.
```
然后：`Use Easy UI Canvas to design a component library for a bookkeeping app: buttons, inputs, cards and list items.` 点开它给你的链接，按 `C` 点元素写评论。

**方式二：手动**（Python 3.9+）
```bash
git clone https://github.com/karlarso/easy-ui-canvas.git
cd easy-ui-canvas
python3 scripts/canvas.py ensure-list                  # 列表页 http://127.0.0.1:4042/
python3 scripts/canvas.py new --name "My first canvas"  # 用示例创建并启动一个画板，输出里有 URL
python3 scripts/canvas.py comments --canvas <id>        # 读取评论（agent 用）
python3 scripts/canvas.py reply --canvas <id> --comment-id <评论id> --status changed --text "改了什么"
```
快捷键：`C` 评论模式，`D` 评论面板。

# English

## Easy UI Canvas v0.1.0 — first public release

A local, multi-frame canvas for exploring UI designs. An AI coding agent lays several HTML screens side by side on a zoomable, pannable board; you **click an element and comment on it**; the agent reads the comments in the next session, changes the design and replies. It needs only the Python 3 standard library, no account, no token, and your data stays on your machine.

### ✨ Highlights
- 🗂️ **Multi-frame canvas (Tile view)**: zoom, pan, minimap, fit-to-window. Frames are HTML/CSS fragments written by the agent — real code, not images. Frames can be grouped into titled sections, each with its own column count.
- 💬 **Element comments**: click any element (or the whole frame, a frame title, a group title bar, or a free-standing note on the board). Track status as pending / changed / needs discussion, "Copy for AI", and let the agent read and reply from the command line.
- 📱 **Flow view and phone preview**: put `data-goto` on buttons to make a prototype clickable. Comment mode also works in the Flow view (clicks select instead of jumping). `/m/` is a read-only phone page with a QR code (the phone must be able to reach a non-loopback bind address). `data-keep-scroll` keeps scroll position between states.
- 🕘 **Snapshots**: keep earlier revisions with their comments and look back read-only.
- 📋 **Many canvases, one list page**: each canvas is a small server; the list page starts, stops and removes them (removal moves to `trash/`, recoverable).
- 📤 **UI hand-off export**: one ZIP with offline pages, screenshots, assets and `HANDOFF.md` (needs optional tools you install yourself: Node.js, Playwright, Chromium/Chrome).
- 🌐 **English and Chinese UI** (switch on the list page; also covers server errors and CLI output).
- 🪶 **No build step, no CDN, no third-party Python packages.** A canvas is plain files in a directory, git-friendly.
- 🤖 **Agent skill** for Claude Code / Cursor / Codex: `SKILL.md` + `DEPLOY.md`; one sentence lets your assistant deploy it, and there is a second sentence for "already running, install the skill only".

### What changed since the early commits
- Comments in the Flow view (#11)
- Comments across the whole board: free-standing notes and group title bars (#10)
- Tile view sectioned by group, per-section columns (#8)
- Fix: Space always types in the comment box (#9)
- `data-keep-scroll` keeps inner scroll position between frames in Flow view (#6)
- Docs: one-sentence deploy / skill-only install, usage examples, Chinese polish, CONTRIBUTING, SECURITY

### ⚠️ Known limitations
- **No authentication.** By default it listens on `127.0.0.1` only and rejects non-loopback `Host` headers. If you bind to `0.0.0.0` or a LAN address, anyone who can reach it can read/change comments and delete canvases — use trusted networks only.
- macOS and Linux only (Windows via WSL); Python 3.9+.
- The page does not auto-refresh: reload the browser after the agent edits frames or replies.
- Scripts inside frame fragments do not run; never import untrusted third-party pages as frames.
- The `/m/` phone preview is read-only and needs a non-loopback bind to be reachable from a phone.
- UI hand-off export depends on optional external tools (not bundled, never auto-installed); the ZIP contains no comments and there is no one-step "import ZIP" command (the agent unpacks it and builds a new canvas from `HANDOFF.md`).
- It is for comparing UI directions and states, not for shipping production apps.
- External pull requests are not accepted for now (see CONTRIBUTING.md); issues are welcome.

```text

```
Then: `Use Easy UI Canvas to design a component library for a bookkeeping app: buttons, inputs, cards and list items.` Open the link it gives you, press `C` and click an element to comment.

**Option 2 — manual** (Python 3.9+)
```bash
git clone https://github.com/karlarso/easy-ui-canvas.git
cd easy-ui-canvas
python3 scripts/canvas.py ensure-list                  # list page at http://127.0.0.1:4042/

python3 scripts/canvas.py comments --canvas <id>        # read comments (what the agent does)
python3 scripts/canvas.py reply --canvas <id> --comment-id <comment id> --status changed --text "what changed"
```
Shortcuts: `C` comment mode, `D` comments panel.
