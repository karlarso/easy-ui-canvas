Shortcuts and controls

CTurn add-comment mode on/off
DTurn the design comments panel on/off
Shift + CWhile the panel is open: select all comments and copy them for AI
EnterSave the comment being added or edited
Shift + EnterNew line in the comment box
EscClose the current popup and keep comment mode
Mouse dragDragging inside a scrollable demo screen scrolls that screen; dragging anywhere else pans the canvas
Two-finger swipePan the canvas
WheelA continuous burst of scrolling (it ends after a pause of more than 0.18 s; trackpad inertia counts as the same burst) locks its target when it starts: if it starts over a scrollable demo screen the whole burst only scrolls that screen, even at its edge (the screen gets a light-blue outline while locked); if it starts on empty space or in a direction the screen cannot scroll, the whole burst pans the canvas. To scroll the other target, pause and scroll again
Space + wheelForce the whole burst to pan the canvas while the pointer is over a demo screen
Shift + wheelPan the canvas sideways, or scroll a scrollable demo screen sideways
Two-finger pinch
Ctrl/⌘ + wheel		Zoom around the pointer
Ctrl/⌘ + +/−Zoom the canvas; toolbar and comment box keep their size
Ctrl/⌘ + 0Reset the canvas to 100%
Alt + wheelScroll only the screen under the pointer, never pan the canvas
Space + drag
Middle-mouse drag		Pan the canvas
HistoryPick a snapshot from the toolbar “History” menu to view the pages and comments of that version, read-only. You cannot add, edit or delete comments there; use “Back to current version” at the top to return to the latest.
Flow viewToolbar “Flow”: the phone screen is on the left (auto-scaled to fit), actions and status on the right (back, back to start, current draft, page n of m, frame ID, title and subtitle); in a narrow window the phone is on top and the actions below. Buttons in a frame that carry data-goto jump when clicked; buttons without it show “End of demo”. “Back” follows the history stack, “Back to start” goes to flow_start (or the first frame). Comments work in the flow view too: turn on comment mode (C) and a click selects an element instead of jumping; no zoom or drag. Reloading keeps you on the same page of the flow view (address bar #view=flow&frame=…, history versions add rev); click “Tile” to go back.
Mobile previewToolbar “Mobile preview” shows a QR code and a link; scan it with a phone to open the read-only mobile preview page (/m/, with ?rev=).
MinimapDrag the viewport box to pan; click outside the box to jump there

While typing, composing with an IME, or with a popup open, C, D and Shift+C do nothing. In comment mode, click an element to add a comment; dragging still pans the canvas.
