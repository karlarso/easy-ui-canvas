# Security policy

Easy UI Canvas has **no authentication**. Use it only on your own machine or on a network you trust. By default every server binds to `127.0.0.1`; open it to other devices only when you understand the risk.

If you find a security issue, please report it privately through GitHub's **Private vulnerability reporting** (the "Report a vulnerability" button under this repository's Security tab) instead of opening a public issue.
